SQL Export機能について

※ SQL Export機能は標準ではOFFです ※

SQL Export機能を利用するためには以下の方法で有効にしてください。

01.PostgreSQLかMySQLのデータベースを用意してください。
02.config.cgi内にデータベース情報を記述し行頭の＃を外してください。
03.export.sql.cgiにSQL文を書いてください。
04.完了

※ サニタイジング処理はしているつもりですがインジェクションが発生しないか確認してください。
※ SQLインジェクションくらっても責任がとれないのでしっかりと脆弱性の確認を行って下さい。
※ 心配な人は絶対に使わないでください。
